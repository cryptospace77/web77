# CryptoSpace77 — web77

Crypto Space 77 is a lightweight, open-source, decentralized, social media web frontend for the hive blockchain.

It is designed as a single-page application (SPA) that runs directly in your browser, with minimal requirements. You can also run it locally on your PC, making the frontend more resilient to censorship or availability issues at the web-hosting level.

## Features

- Decentralized social media frontend
- Powered by the hive blockchain
- Lightweight browser-based SPA
- Core features supported: posting, upvoting, commenting, feed, profiles, tags, communities
- Supports Hive Keychain and login with your Posting key on mobile
- Can be run locally on your own PC
- Open source (MIT license)

## Production

Visit the live version:

https://cryptospace77.com/

## Run locally

Clone or download the repository, then start the included Python server:

```
python server.py --port 8777
```

The default port is **8777**.

Then open 127.0.0.1:8777 in your web browser.
